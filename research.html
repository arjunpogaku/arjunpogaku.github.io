Grounding language models in structure

A language model can write a query that runs perfectly and still answers the wrong question. This line of work builds the missing half: explicit knowledge graphs over real measurement data, plus a domain knowledge base that constrains what the model is allowed to say.

Structured Domain Grounding for Natural-Language Querying of Japan’s Large-Scale PM2.5 Knowledge Graph

Arjun Chakravarthi Pogaku, Uday Kiran Rage, Padma Selvaraj, Naveen Kumar Pera

Japan’s air-quality monitoring network produces measurements at a scale no analyst can read directly. This work turns that record into JPM2KG, a knowledge graph built from more than 71 million observations across 1,116 monitoring stations, then asks whether a language model can be trusted to query it in plain language.

To answer that honestly rather than anecdotally, the paper introduces AirCypher-150, a benchmark of 150 natural-language and Cypher query pairs validated by execution, and a Domain Knowledge Base that supplies canonical domain values, domain rules, query policies, and worked examples on top of the bare graph schema. Six prompting configurations were evaluated across four open-source models and a fine-tuned Text2Cypher baseline.

Schema alone is not grounding

Prompting with the graph schema produced queries that almost all executed cleanly, yet were semantically correct almost never — a pooled VM-F1 of 0.001. Adding canonical domain values and structured domain knowledge raised the same measure to 0.416. An executable query is not a correct answer, and the gap between those two things is where the domain knowledge has to go.

PAMI-GPT: knowledge-grounded LLMs for reliable pattern mining workflow generation

Pattern mining libraries are powerful and awkward to drive. PAMI-GPT takes a described analysis in plain language and produces a workflow that actually runs, grounding generation in what the library can really do rather than what a model assumes. It began as a conversational custom-GPT presented at MCSoC and was formalized into a knowledge-grounded framework for the journal version.
