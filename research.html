Research

A single question runs through my work: can a system tell you why, and not only what comes next? Prediction alone leaves no trail back to the evidence. Building an explicit graph of relationships does — and once that structure exists, a language model can be held to it.

Knowledge graphs and grounded querying

A language model can write a query that runs perfectly and still answers the wrong question. My work builds the missing half: explicit knowledge graphs over real measurement data, and a domain knowledge base that constrains what the model is allowed to say.

Accepted · BDA 2026 Presented at BITS Pilani Goa. Proceedings forthcoming.

Structured Domain Grounding for Natural-Language Querying of Japan’s Large-Scale PM2.5 Knowledge Graph

Arjun Chakravarthi Pogaku, Uday Kiran Rage, Padma Selvaraj, Naveen Kumar Pera

Japan’s air-quality monitoring network produces measurements at a scale no analyst can read directly. I built JPM2KG, a knowledge graph of more than 71 million observations across 1,116 monitoring stations, to ask whether a language model can be trusted to query that record in plain language.

To answer it honestly rather than anecdotally, the paper introduces AirCypher-150, a benchmark of 150 natural-language and Cypher query pairs validated by execution, and a Domain Knowledge Base supplying canonical domain values, domain rules, query policies, and worked examples on top of the bare graph schema. I evaluated six prompting configurations across four open-source models and a fine-tuned Text2Cypher baseline.

71M observations in the graph
1,116 monitoring stations
150 execution-validated query pairs

Schema alone is not grounding

Prompting with the graph schema produced queries that almost all executed cleanly, yet were semantically correct almost never — a pooled VM-F1 of 0.001. Adding canonical domain values and structured domain knowledge raised the same measure to 0.416. An executable query is not a correct answer, and the gap between those two things is where the domain knowledge has to go.

A Symbolic Knowledge Graph Framework for Spatiotemporal Traffic Congestion Analysis

Arjun Chakravarthi Pogaku, Uday Kiran Rage, Vanitha Bandi

The same approach applied to road networks, and the work the air-quality graph grew out of. Deterministic rules turn high-frequency congestion readings into a graph of spatial, temporal, and congestion-level relationships; a domain-constrained model then generates Cypher directly from a plain-language question. Every answer traces back to the nodes and edges that produced it, rather than arriving as a prediction with no account of itself.
